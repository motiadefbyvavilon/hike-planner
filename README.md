# ПоходПлан — планирование походов

Фронтенд-приложение на **Vue 3 + Vite**: планирование туристических походов —
маршрут, группа, снаряжение и план по дням в одном месте.

## Возможности

1. **Мои походы**
   - Создание похода: название, регион, даты, сложность, описание.
   - Карточки походов с датами, длиной маршрута, размером группы и прогрессом сборов.
   - Валидация дат (окончание не раньше начала).

2. **Группа похода**
   - Добавление и удаление участников, роль «Организатор» защищена от удаления.
   - Защита от дубликатов участников.

3. **Снаряжение**
   - Автоматический базовый чек-лист при создании похода (палатка, горелка, аптечка…).
   - Отметки «собрано», назначение несущего участника, прогресс в процентах.
   - Свои пункты снаряжения по категориям; при удалении участника его снаряжение освобождается.

4. **План по дням**
   - Дни маршрута с названием, километражом и заметками (ночёвка, вода, заброска).
   - Добавление/удаление дней, автоматический пересчёт общей дистанции.

5. **Каталог маршрутов**
   - 6 готовых маршрутов (Байкал, Алтай, Карелия, Крым, Фанские горы, Подмосковье).
   - «Спланировать поход» создаёт поход по маршруту с готовым чек-листом.

Данные хранятся в `localStorage` браузера (демо-режим без бэкенда).

## Стек

- Vue 3 (Composition API, `<script setup>`)
- Vite
- Vue Router 4
- Pinia
- Без UI-библиотек: собственные компоненты и дизайн-токены (OKLCH)

## Запуск

```bash
npm install
npm run dev      # дев-сервер
npm run build    # продакшн-сборка в dist/
npm run preview  # просмотр продакшн-сборки
```

## Структура

```
src/
├── main.js
├── App.vue                # каркас: шапка, навигация, тосты
├── router/                # Мои походы / Поход / Каталог маршрутов
├── data/catalog.js        # каталог маршрутов и базовый чек-лист снаряжения
├── stores/trips.js        # Pinia: походы, участники, снаряжение, дни
├── views/
│   ├── TripsView.vue       # список походов + создание
│   ├── TripDetailView.vue  # вкладки: участники / снаряжение / план по дням
│   └── RoutesView.vue      # каталог готовых маршрутов
└── components/
    └── ToastStack.vue      # всплывающие уведомления
```
